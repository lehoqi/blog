# 主题冒险闯关验收清单

- 日期：2026-05-28
- 关联设计：`docs/superpowers/specs/2026-05-28-themed-adventure-upgrade-design.md`
- 用途：实现和验收时逐项检查，防止遗漏动画、音效、语音和非文字可玩性。

## 1. 逻辑一致性

- [ ] 一局仍然只有 5 题。
- [ ] 答错不推进冒险进度。
- [ ] 每题只有首次答对推进一次冒险进度。
- [ ] 第 1-4 题播放冲刺段。
- [ ] 第 5 题进入 Boss/终点段。
- [ ] Boss 登场每局只出现一次，重试第 5 题不重复打断。
- [ ] 通关结算只执行一次，不重复发金币、星星或勋章。
- [ ] 冒险状态只存在当前局内存，不改变 records/garage 存档结构。
- [ ] 清除记录后，现有 records/names/garage 行为不变。

## 2. 酷炫动画覆盖

- [ ] 冒险入场有明显动画：座驾入场、主题背景、粒子或闪光。
- [ ] 答对第 1-4 题有明显冲刺动画：车辆移动、拖尾、速度线或粒子。
- [ ] 连对有增强：速度、粒子、震屏、闪光或音效层次随 streak 增强。
- [ ] 第 5 题 Boss 登场有强反馈：压暗、放大、砸入、警报或鼓点。
- [ ] Boss 受击或终结技有主题差异，不是五族完全同一效果。
- [ ] Boss 击败有明显结果：爆炸、净化、逃跑、碎裂或星云化。
- [ ] 通关奖励有大反馈：烟花、金币雨、车辆凯旋或全屏庆祝。
- [ ] reduced-motion 下动画降级但状态正确。
- [ ] 所有动画都有超时兜底，不会卡住下一题或结果页。

## 3. 音效覆盖

- [ ] 冒险入场播放主题启动音效。
- [ ] 答对冲刺播放主题冲刺音效。
- [ ] 连对增强时音效也增强或叠加。
- [ ] Boss 登场播放警报、鼓点或低频冲击音。
- [ ] Boss 受击播放攻击/撞击/治疗/喷水/爆裂等音效。
- [ ] Boss 击败播放胜利音效。
- [ ] 金币雨或奖励播放奖励音效。
- [ ] 音效不受语音静音按钮控制，保持现有警笛一致性。
- [ ] AudioContext 不可用时静默失败，不影响流程。

## 4. 语音覆盖

- [ ] 每个新增按钮或可见提示都有对应语音。
- [ ] 冒险入场目标有语音。
- [ ] 地图主题和 Boss 名称有语音。
- [ ] Boss 登场有语音。
- [ ] 答对冲刺或阶段推进有语音，且不掐断题目语音。
- [ ] Boss 击败和通关奖励有语音。
- [ ] 结果页新增冒险文案接入 `speakQueue`。
- [ ] 多句播报使用 `speakQueue`，不连续裸调 `speak` 互相截断。
- [ ] 语音静音后，所有语音静默，流程仍可玩。

## 5. 非文字可玩性

- [ ] 主题靠 emoji、颜色、背景和音效区分，不只靠文字标题。
- [ ] 进度靠 5 段进度点、座驾位置或数字表达。
- [ ] Boss 状态靠大图标、颜色、动作或数字表达。
- [ ] 奖励靠金币、星星、烟花、勋章图标表达。
- [ ] 儿童不读文字也能知道：现在在第几步、是否答对、是否打败 Boss、是否获得奖励。
- [ ] 新增文字不遮挡题目数字、答案区或数字键盘。

## 6. 五族完整性

- [ ] `police` 有地图、Boss、冲刺、终结、音效、语音。
- [ ] `ambulance` 有地图、Boss、冲刺、终结、音效、语音。
- [ ] `fire` 有地图、Boss、冲刺、终结、音效、语音。
- [ ] `everyday` 有地图、Boss、冲刺、终结、音效、语音。
- [ ] `adventure` 有地图、Boss、冲刺、终结、音效、语音。
- [ ] 装备不同 family 座驾后，冒险主题自动切换。
- [ ] 未知或异常 family 安全回退，不报错卡死。

## 7. 回归检查

- [ ] `node --test tests/garage.test.js` 通过。
- [ ] 现有题目生成、主题题概率、tagScores 不回归。
- [ ] 现有金币、星星、勋章、排行榜不回归。
- [ ] 车库装备后头像、题库主题、冒险主题一致。
- [ ] 默认乐乐警车、昊昊救护车行为合理。
- [ ] 移动端宽度下文字和动画不互相覆盖。
